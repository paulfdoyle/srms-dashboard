Definitions
Learners: distinct learners in the latest GLR snapshot for the term.
Scheduled programmes: distinct programme codes in the latest Banner schedule snapshot for the term.
Programmes without learners: scheduled programmes that do not appear on any learner record for the term.
Scheduled programmes missing school: scheduled programmes whose Banner school code is blank.
Unscheduled programmes missing school (has learners): programmes with learners but not scheduled for the term, whose Banner school code is blank.
Programmes missing school (no learners or schedule): programmes with blank Banner school code and no activity in schedule or learners for the term.
GLR programmes missing schedule: programme codes present on learner records but not present in the schedule snapshot for the term.
Scheduled modules: distinct module codes in the latest Banner schedule snapshot for the term (not CRNs).
Modules without enrolments: scheduled module codes that do not appear in classlists for the term.
“with multiple CRNs”: module codes that appear with more than one CRN in the schedule for the term.
CRNs: distinct CRNs in the Banner schedule snapshot; “w/o enrol.” compares to classlists CRNs for the term.
Learner Metrics:
Missing programme: learners with no programme recorded for the term.
Multiple programmes: learners linked to more than one programme for the term.
Missing school: learners whose programme has no school assigned.
Missing campus: learners with no campus recorded.
Learners in programmes missing schedule: learners whose programme is not present in the schedule snapshot for the term.
Missing enrolments: learners with no module enrolments in classlists for the term; n/a when classlists are unavailable.
